Your files

Where your library lives.

Your library is stored on your own computer, in a single folder, as a plain text file. Nothing is uploaded and there is no account to register.

The folder

Linux 
~/.config/parallax-launcher/
Windows 
%APPDATA%\parallax-launcher\

Most of what is in there belongs to the browser engine the app is built on — caches it will rebuild if you delete them. Three things are yours:

  • Parallax_Accounts/ — one folder per library, holding Library.txt and the artwork you have imported.
  • app_settings.json — your language, sort order and the rest of the settings screen.
  • api_keys.json — the key from the artwork service, if you added one.

The library itself

Library.txt is a plain text file with one block per game, simple enough to read and edit by hand. A database would be tidier, but a text file can still be opened and understood years later, with or without Parallax.

One game, as stored 
---
Name: Half-Life 2
Category: Steam Library
Platform: Steam
Status: Installed
Path: /home/you/.local/share/Steam/steamapps/common/Half-Life 2
PlayTime: 79.7167
SteamAppId: 220
CompatTool: auto
---

Backing it up

Copy Parallax_Accounts/ somewhere safe. That is the whole backup — the library, the artwork, every account. Putting it back is the same operation the other way round, with Parallax closed.

The app also has Export on the account screen, which packs the same thing into one file for you.

Moving to another machine

Copy the folder across and Parallax finds it. Your games' locations will not match, though — a different machine keeps its games somewhere else, and possibly on a different drive letter. Refresh the library once and every Steam game corrects itself; the ones you added by hand need pointing at again.

Removing every trace

Uninstalling Parallax deliberately leaves this folder alone, so that reinstalling picks up where you left off. If you want it gone, delete it yourself:

Linux 
rm -r ~/.config/parallax-launcher

Nothing in there is a game. Deleting it loses your shelf, your artwork and your recorded hours — never the games themselves.

What leaves your machine

Three places, and each of them only when you ask: Steam, for the list of games you own and the hours you have played; SteamGridDB, for artwork; GitHub, to see whether there is a newer version. That is the entire list. Your library is never sent anywhere, there is no analytics of any kind in the app, and there is no account to sign in to.
