Your library files

This page explains where your library is stored, how to back it up, how to move it to another computer and how to remove it completely.

Location

Linux 
~/.config/parallax-launcher/
Windows 
%APPDATA%\parallax-launcher\

Most of the contents of this folder belong to the browser engine the application is built on and are caches that are rebuilt if deleted. Three items are yours:

  • Parallax_Accounts/ — one folder per library, containing Library.txt and the artwork that has been downloaded.
  • app_settings.json — your language, sort order and the remaining settings.
  • api_keys.json — the key for the artwork service, if you have entered one.

The library file

Library.txt is a plain text file containing one block per game. It can be read and edited with any text editor. A database would be more compact, but a text file remains readable years later, with or without Parallax.

One game as stored 
---
Name: Half-Life 2
Category: Steam Library
Platform: Steam
Status: Installed
Path: /home/you/.local/share/Steam/steamapps/common/Half-Life 2
PlayTime: 79.7167
SteamAppId: 220
CompatTool: auto
---

Backing up

Copy the Parallax_Accounts/ folder to another location. This contains the complete backup: the library, the artwork and every account. Restoring is the same operation in reverse, with Parallax closed.

The application also provides Export on the account screen, which packages the same data into a single file.

Moving to another computer

Copy the folder to the other computer and Parallax will use it. Game locations will not match, because another machine stores its games elsewhere and possibly on a different drive. Refresh the library once and Steam games are corrected automatically; games added manually need to be located again.

Removing everything

Uninstalling Parallax leaves this folder in place so that reinstalling continues from the same state. To remove it, delete the folder:

Linux 
rm -r ~/.config/parallax-launcher

The folder contains no games. Deleting it removes your library, artwork and recorded play time, but not the games themselves.

Network connections

Parallax connects to three services, and only when you request it: Steam, for your list of games and recorded play time; SteamGridDB, for artwork; and GitHub, to check for a newer version. Your library is not transmitted anywhere, the application contains no analytics, and there is no account to sign in to.
