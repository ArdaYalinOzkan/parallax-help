Automation

Command line

Parallax includes a command-line interface for reading the library, starting games and editing entries. It is intended for scripts and for AI assistants working with a user's library.

Running it

No additional installation is required. The command-line interface is part of the Parallax installation already present on the machine and is accessed with --cli. Everything after that flag is the command. 

parallax-launcher --cli games --json
./Parallax-Launcher.AppImage --cli games --json
"C:\Path\To\Parallax Launcher.exe" --cli games --json

On Windows the installation location is chosen during setup, so there is no single path to quote; the Start menu shortcut points to the correct file. No window is opened and no display is required, so the interface also works over SSH and inside containers. It exits with 0 on success and 1 on failure.

A shorter alias can be defined once:

alias parallax='parallax-launcher --cli'

Notes for automated use

Pass --json to every command. The output is then a single JSON object containing an ok field, and on failure an error code and a message. Error codes are stable; messages are not, so conditions should be based on the code. 

{
  "ok": false,
  "error": "AMBIGUOUS_GAME",
  "message": "\"half\" matches 7 games: Half-Life, Half-Life 2, … Use the id."
}

Games are identified by id or by name, and the name does not need to be exact: half life 2 matches Half-Life 2. If an inexact name matches more than one game, the command lists the matches instead of selecting one, and the id from that list should be used. Identifiers are stable and are not reused.

Commands

parallax accounts
parallax games [--installed] [--search TEXT] [--sort name|playtime]
parallax game <id|name>
parallax find <name> [--appid N]
parallax fields

parallax launch <id|name>
parallax add <name> [--path P] [--steam-appid N] [--platform P]
parallax set <id|name> <field> <value>
parallax scan

--account NAME can be used with any command. Without it, the library most recently used by the application is selected. If several libraries exist and none has been used, the command asks rather than choosing one.

  1. games

    Lists every game in the library. --installed limits the result to games present on this machine and --search to titles containing the given text. Each entry contains id, name, platform, status, installed, path, playTimeHours, steamAppId, category, launchOptions and compatTool.

  2. launch

    Starts a game in the same way as the Play button: through Steam for Steam games, otherwise using the compatibility tool set for that entry. The command returns once the game has been started and does not wait for it to close. A game with a Steam id is passed to Steam whether or not it is installed. A game with neither a Steam id nor a location fails with NO_PATH.

  3. find

    Searches this computer for a game without modifying anything, beginning with Steam's own records and then the usual installation folders on each drive. Each location is returned with the executable that would be used. An empty result means the game was not found and is not an error.

  4. add

    Adds an entry to the library. If --path is omitted, the location is searched for and filled in when found. A name already present in the library is rejected with ALREADY_THERE.

  5. set

    Changes a single field. parallax fields lists the fields that are accepted; any other field is rejected rather than written. When path is set, the location is checked and the installation status is updated accordingly.

  6. scan

    Queries Steam for the games that are actually installed, corrects the library and reports every entry that was changed. This is worth running before relying on the installation status of a library that has not been opened recently.

Operations that are not available

There is no command to delete a game, and none to create, rename or delete an account. These operations cannot be undone and are therefore not exposed. Every command listed here is either read-only or makes a change that can be reversed in the application.

Artwork is not downloaded through the command line. That requires API keys and network requests and is handled by the application.

Using it while Parallax is open

Both write to the same file. Parallax monitors its library for changes it did not make and reloads when one occurs, so an edit made here appears in an open window within a second. The exception is a game being edited at that moment, where the version in the application takes precedence. 

parallax games --sort playtime --json | jq '.games[:5][] | .name'
parallax launch "hollow knight" --json
parallax add "Baldur's Gate 3" --json

If a command is missing or the output would be more useful in another form, you can open an issue on GitHub.
