First use

Setting up for the first time

This page describes what to do when you open Parallax for the first time: creating an account, importing your library, adding games and arranging the library view.

  1. 1.

    Create an account

    An account is a name for the library and is stored on this computer. It is not an account with any online service: no data is sent anywhere, and there is no password unless you set one. Two people who share a computer can keep separate libraries.

  2. 2.

    Import your Steam library

    Enter your Steam profile link or your Steam user name. Parallax then imports the games on your account. Your Steam profile must be public: game lists are private by default, and a private profile returns an empty list rather than an error message.

    Cover images and banners are downloaded at the same time. A large library takes a few minutes, and you can continue using the program while this runs.

  3. 3.

    Add games from other sources

    Games from Epic, GOG, the Xbox app, emulators or your own builds can be added manually. Enter the name of the game and Parallax searches your drives for it, starting with Steam's own records and then the folders where games are normally installed.

    If the game is found, its location is filled in automatically. If it is not found, you are asked to select the file yourself.

  4. 4.

    Arrange the library view

    Games can be sorted by name, by hours played or by the dominant colour of the cover image. Sorting by colour is useful in a large library, where a game is often easier to recognise by its cover than by its title.

    Filters limit the view to installed games or to a single platform. The setting is remembered between sessions.

Starting a game

Steam games are started through Steam, which handles Proton, cloud saves and the overlay. Other games are started by Parallax directly, using Proton or Wine on Linux when the game is built for Windows. Play time is recorded in both cases. If a game is not installed, Parallax offers to locate or download it.

Each game has a Properties panel containing the settings that determine how it starts: the Proton version, launch options and environment variables. Default values are used unless you change them, and most games require no changes.

If something does not work as described, see Troubleshooting.
