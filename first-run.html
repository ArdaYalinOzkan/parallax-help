First run

The first ten minutes.

What to do when you open Parallax for the first time: create an account, import your library, add games and arrange them.

  1. 1

    Make an account

    Not an account with anyone — a name for this library, kept on this machine. Nothing is sent anywhere and there is no password unless you set one. Two people sharing a computer can have a shelf each; most people make one and never think about it again.

  2. 2

    Bring in your Steam games

    Paste your Steam profile link, or just your Steam name, and Parallax fetches everything you own. It needs your profile to be public — Steam hides game lists by default, and a private one comes back empty rather than with an error worth reading.

    Cover art and banners are fetched at the same time. A large library takes a few minutes; you can use the app while it works.

  3. 3

    Add what Steam does not know about

    Games from Epic, GOG, the Xbox app, an emulator, or something you compiled yourself. Type the name and Parallax looks for it on your disk — Steam's own records first, then the folders games are usually kept in, on every drive.

    If it finds it, the location is filled in for you. If it does not, it asks you to point at the file rather than guessing.

  4. 4

    Arrange the shelf

    Sort by name, by hours played, or by the colour of the cover art — which sounds like a novelty until you have two hundred games and find you remember what a game looks like long before you remember what it is called.

    Filters narrow it to what is installed, or to one platform. The setting sticks, so the shelf looks the way you left it.

Then press Play

A Steam game is started through Steam, which handles Proton, cloud saves and the overlay. Anything else Parallax runs itself, on Linux through Proton or Wine when the game is a Windows one. Hours are counted either way, and a game you have not installed offers to find or fetch it rather than doing nothing.

Every game has a Properties panel for the things that decide how it starts — which Proton build, launch options, environment variables. Untouched, it picks sensible defaults; it is there for the one game a year that needs something unusual.

Something not behaving? The troubleshooting guide covers what goes wrong most often.
