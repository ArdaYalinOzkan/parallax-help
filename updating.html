Updates

How updates reach you.

How updates reach you depends on how Parallax was installed. Each method is described below.

.AppImage

The app fetches it

One file, so it can replace itself. It looks once a day, says when there is something newer, and downloads only after you press the button. Nothing arrives unasked.

.exe

The app fetches it

The same, and it downloads only the parts that changed rather than the whole installer. Because it installs for your account alone, updating needs no administrator password.

.deb

Either, your choice

On its own it updates itself through dpkg, which asks for your password the way any install does. Add the repository and your system takes over instead.

Letting apt do it instead

Add the package repository once and Parallax joins your ordinary updates — one command, or one button in your software centre, brings it up to date along with everything else. The three lines are here.

The app notices when you have done this and steps back. Two updaters chasing the same package would offer you the same version twice, and one of them would be wrong about how to install it.

Knowing an update is really ours

Every released file carries a signed statement naming the commit and the workflow that built it, so a download can be traced back to the source it came from rather than taken on trust. From the repository, apt checks a signature before it will install anything, and refuses if it does not match. How to check a file yourself.

If you would rather it did not ask

Settings → About → Check automatically. With it off, nothing contacts GitHub unless you press the button yourself.

An update check is a request to a server, which means an IP address and a version number leave your machine. That is worth being able to decline, so you can.
