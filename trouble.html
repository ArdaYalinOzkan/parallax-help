Troubleshooting

When something does not work.

The most common problems and what causes them. Open the section that matches your situation.

It will not open at all Linux, AppImage

Almost always one of two things, and they look identical from outside: nothing happens when you click.

First, the file may not be allowed to run. A downloaded file is not executable until you say so — see the AppImage steps.

Second, your menu entry may point at a file that is no longer there. An AppImage whose filename carries a version number gets a new name every update, and the menu keeps pointing at the old one. Removing the stale entry and starting the new file once fixes it for good:

rm ~/.local/share/applications/parallax-launcher.desktop

Then run the AppImage directly; it puts a correct entry back. Newer releases are named without a version for exactly this reason.

If it still does nothing, run it from a terminal — it will say why, and that message is worth putting in an issue.

A game says it is installed, but it is not Steam games

Uninstalling through Steam removes its record of the game but often leaves the folder behind — empty, or with a settings file in it. Anything that judges by the folder is fooled, and Parallax used to be.

It now asks Steam rather than the disk. Use Refresh library and the wrong ones correct themselves. The reverse works too: a game you installed while Parallax was closed is found again.

A game with an update waiting still counts as installed, which is the honest answer — it is on your disk and it will start.

A game will not start All systems

If it is a Steam game, Parallax hands it to Steam and Steam does the rest — so if it fails, it usually fails in Steam, and Steam says why. Try starting it there once.

If it is a game you added yourself, the location may point at the wrong file. A folder full of executables is a guess, and Parallax picks the most likely one; open Edit and point it at the right binary if it chose badly.

On Linux, a Windows game needs Proton or Wine. Properties shows which one is in use and lets you change it. If no Proton build is installed, Steam installs one the first time you run any Windows game through it.

The artwork never arrives Covers and banners

Steam's own art covers Steam games and needs nothing from you. Everything else — games from other shops, older titles, anything Steam never sold — comes from a community library that asks for a free key. Getting one takes about a minute.

A whole library at once takes a while, and images arrive as they are found rather than all together. If a game keeps its placeholder after everything else has filled in, its name is probably the problem: art is looked up by name, and a name with an edition or a subtitle attached often matches nothing.

Rename it to the plain title, or set the image yourself from Edit — a file from your disk is accepted, and it is never overwritten afterwards.

Importing from Steam finds nothing Steam import

Steam hides game lists by default. A private profile answers the request politely and says nothing, which is indistinguishable from owning no games.

In Steam: Profile → Edit Profile → Privacy Settings, and set Game details to Public. You can set it back afterwards — the import only needs to succeed once.

Install does nothing, or Steam refuses Family sharing

Steam will only install a game the signed-in account owns. A game shared with you through a family, or one you own somewhere else entirely, cannot be fetched that way — Steam is asked for something it has no record of you having, and nothing happens.

The button looks on your own disk first now, and finds the game if it is there. When it is not, it offers both roads: let Steam download it, or point at the copy you already have.

It is slow, or the window stutters Large libraries

The loading screen is doing real work: covers are decoded and banners fetched before the shelf appears, so that scrolling it afterwards is smooth. A library of a few hundred games takes a couple of seconds the first time and less afterwards.

If the window itself stutters while you scroll, it is worth checking that your machine is using its graphics card rather than falling back to software rendering — that shows up as everything being slow, not only Parallax.

Something has gone, and I want it back Accounts and libraries

A deleted account is not deleted immediately — it waits, and can be restored from the account screen. Your library is a plain text file you can also copy yourself; where it lives, and how to back it up.

Uninstalling Parallax never touches that folder. Reinstalling picks up exactly where you left off, which is also why removing the program does not remove your library unless you delete the folder yourself.

Not here? Open an issue — say what you did and what happened, and it gets looked at.
