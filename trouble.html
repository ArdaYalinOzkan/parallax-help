Troubleshooting

Troubleshooting

This page lists the most common problems and their causes. Open the section that matches your situation.

Parallax does not open Linux, AppImage

There are two common causes, and both appear the same way: nothing happens when the file is opened.

First, the file may not have permission to run. A downloaded file is not executable until you allow it. See the AppImage installation steps.

Second, the application menu entry may point to a file that no longer exists. An AppImage whose file name contains a version number is renamed with each update, while the menu entry continues to reference the previous name. Removing the outdated entry and running the new file once resolves this permanently: 

rm ~/.local/share/applications/parallax-launcher.desktop

Then run the AppImage directly. It creates a correct menu entry. Current releases no longer include the version number in the file name for this reason.

If the program still does not start, run it from a terminal. The error message shown there is useful and can be included in an issue report.

A game is shown as installed but is not Steam games

When Steam uninstalls a game it removes its own record of it, but the game folder often remains on disk. The folder may be empty or contain only a configuration file, so the presence of a folder is not a reliable indication that a game is installed.

Parallax now takes this information from Steam rather than from the disk. Select Refresh library and incorrect entries are corrected. The same applies in reverse: a game installed while Parallax was closed is detected again.

A game with a pending update is still counted as installed, because it is present on the disk and can be started.

A game does not start All systems

For Steam games, Parallax passes the request to Steam, which performs the launch. If the game fails to start, the failure usually occurs in Steam and Steam reports the reason. Try starting the game from Steam once.

For games added manually, the recorded location may point to the wrong file. Where a folder contains several executable files, Parallax selects the most likely one. If the selection is incorrect, open Edit and select the correct file.

On Linux, a Windows game requires Proton or Wine. The Properties panel shows which is in use and allows it to be changed. If no Proton version is installed, Steam installs one the first time a Windows game is run through it.

Cover images do not appear Artwork

Images for Steam games come from Steam and require no configuration. Images for all other games, including titles from other stores and older releases, come from a community database that requires a free API key. See API keys.

Downloading images for an entire library takes some time, and images appear individually as they are found. If a game keeps its placeholder image after the others have loaded, the cause is usually its name: images are matched by title, and a title that includes an edition name or subtitle often does not match any entry.

Change the name to the plain title, or set the image manually from Edit. A file from your own disk is accepted and is never overwritten afterwards.

Steam import returns no games Steam import

Steam hides game lists by default. A private profile returns an empty response, which is indistinguishable from an account that owns no games.

In Steam, open Profile → Edit Profile → Privacy Settings and set Game details to Public. The setting can be changed back afterwards, as the import only needs to succeed once.

Install does not work, or Steam refuses Family sharing

Steam installs only games owned by the account that is signed in. A game shared through Steam Family, or purchased elsewhere, cannot be installed this way, and Steam does not respond to the request.

Parallax now searches your own drives first and uses the game if it is already present. If it is not, both options are offered: download the game through Steam, or select the copy you already have.

The program is slow or the window stutters Large libraries

The loading screen decodes cover images and downloads banners before the library is displayed, so that scrolling is smooth afterwards. A library of several hundred games takes a few seconds on first load and less on subsequent ones.

If the window itself stutters while scrolling, check whether your system is using the graphics card or has fallen back to software rendering. In that case all applications are affected, not only Parallax.

Recovering a deleted account or library Accounts and libraries

A deleted account is retained for a period and can be restored from the account screen. The library is a plain text file that you can also copy yourself. See Your library files.

Uninstalling Parallax does not remove this folder. Reinstalling continues from the same state, and the library is only removed if you delete the folder yourself.

If your problem is not listed here, you can open an issue on GitHub describing what you did and what happened.
