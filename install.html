Downloading

Your download is starting.

It should begin on its own in a moment. Nothing else is needed from you here — this page is only what to do once it lands.

Download didn't start? Click here All files
Windows

Then run the installer.

  1. 1

    Open the file you just downloaded

    Parallax-Launcher-Setup.exe, usually in your Downloads folder.

  2. 2

    Windows will stop it the first time

    It is not code-signed, so Windows blocks anything it has not seen before. Two clicks get past SmartScreen; Smart App Control needs one setting changed. Both are shown here, with pictures.

  3. 3

    Install where you like

    It installs for your user, so no administrator password is asked for — and none is asked for when it updates itself later.

Linux

Then make it executable and run it.

  1. 1

    Allow it to run

    Right-click the file → Properties → Permissions → Allow executing as program. Or in a terminal:

    chmod +x Parallax-Launcher-*.AppImage
  2. 2

    Double-click it

    Nothing is installed. It adds itself to your application menu on first run, and deleting the file removes the program — the menu entry goes with it.

  3. 3

    It keeps itself current

    It watches for new releases and offers to replace itself. On Debian or Ubuntu you can let your package manager do it instead.
