Windows

Running the installer

  1. 1.

    Open the downloaded file

    The file is named Parallax-Launcher-Setup.exe and is usually in your downloads folder.

  2. 2.

    Allow it to run

    Windows previously blocked this file with a security warning and no longer does, so in most cases nothing further is required. If a warning does appear.

  3. 3.

    Choose the installation location

    The installer asks where to install the program and creates the shortcuts. Parallax is installed for your user account only and does not require an administrator password.

Linux

Running the AppImage

  1. 1.

    Make the file executable

    Downloaded files are not executable by default. In a file manager this is a checkbox in the file properties; in a terminal it is a single command. 

    chmod +x Parallax-Launcher-*.AppImage
  2. 2.

    Run the file

    Double-click the file or run it from a terminal. Parallax adds an entry to your application menu on first launch.

  3. 3.

    Keep it somewhere permanent

    The downloads folder is often cleared. For a file you intend to keep, ~/.local/bin or ~/Applications is a more suitable location.
