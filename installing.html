Installation

This page describes the installation steps for each package type. Open the section that matches the file you downloaded.

Windows Parallax-Launcher-Setup.exe
  1. 1.

    Open the file

    The file is in your downloads folder and is named Parallax-Launcher-Setup-3.7.0.exe or similar. Double-click it to start the installer.

  2. 2.

    Allow it to run

    Windows previously blocked this file with a security warning. It no longer does, so in most cases nothing further is required. If a warning does appear, see Windows security warnings.

  3. 3.

    Choose the installation location

    You select where the program is installed. Parallax is installed for your user account only and does not require an administrator password. When installation is complete, Parallax appears in the Start menu.

Later updates are delivered through the program itself. Parallax checks for new versions and notifies you when one is available.

AppImage Any Linux distribution

An AppImage contains the entire program in a single file. Nothing is installed and no files are placed elsewhere on the system. You keep the file wherever you prefer and delete it when it is no longer needed.

  1. 1.

    Move the file to a permanent location

    The downloads folder is often cleared. For a file you intend to keep, ~/.local/bin or ~/Applications is a more suitable location.

  2. 2.

    Make the file executable

    Linux does not allow a newly downloaded file to run until you permit it. In a file manager this is a checkbox in the file properties. In a terminal it is a single command: 

    chmod +x Parallax-Launcher.AppImage
  3. 3.

    Run the file

    Double-click the file or run it from a terminal. On first launch Parallax adds an entry to your application menu, and you can start it from there afterwards.

Updates: Parallax replaces its own file in place. If the program does not start after an update, see Troubleshooting.

.deb Debian, Ubuntu, Mint, Pop!_OS

There are two options. Installing the file gives you the program. Adding the repository gives you the program and all subsequent updates through the same system that updates the rest of your software.

Installing the file only

Double-click the file, or run:

sudo apt install ./parallax-launcher_3.6.0_amd64.deb

With this method updates are not delivered automatically. Parallax notifies you when a new version is available, and you download the next file yourself.

Adding the repository

Three commands, run once. Parallax is then updated together with your other software whenever you upgrade the system. 

curl -fsSL https://apt.parallaxlauncher.com/key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/parallax.gpg
echo "deb [signed-by=/usr/share/keyrings/parallax.gpg] https://apt.parallaxlauncher.com stable main" | sudo tee /etc/apt/sources.list.d/parallax.list
sudo apt update && sudo apt install parallax-launcher

The key allows your system to verify that an update genuinely comes from this project. Without it, apt refuses the repository.

For what to do after installation, see Setting up for the first time.
