Settings

API keys, and when you need one.

Most features work without a key. Artwork from outside Steam requires one, and it is free.

No key

Finding and starting your games

Installed games are read from Steam's own records on your disk. Hours, Proton settings, launching — none of it touches an API.

No key

Searching for a game to add

Steam's store search finds anything sold there without a key, which is most of what anyone is looking for.

Built in

Importing your whole library

Including games you own but have not installed. A Steam key ships with the app so this works straight away — but it is shared by everyone, and Steam counts requests against it.

Yours to add

Artwork beyond Steam's own

SteamGridDB has hundreds of covers per game where Steam has one, and knows about games Steam never sold. No key ships for it.

Getting one takes a minute

  1. 1

    Sign in at steamgriddb.com

    With your Steam account. There is nothing to fill in and nothing to pay.

  2. 2

    Open the API page in your profile

    steamgriddb.com/profile/preferences/api — generate a key and copy it.

  3. 3

    Paste it into Settings → API

    It is kept in your own config folder and goes nowhere except to SteamGridDB when artwork is being looked up.

Using your own Steam key

Optional, and worth doing if you import often. The bundled key is one allowance divided among everybody who uses Parallax; your own is yours alone. Get one at steamcommunity.com/dev/apikey and paste it into Settings → API. A key you enter is always read before the built-in one.
