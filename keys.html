API keys

This page explains which features require an API key, what the key provides and how to obtain one.

No key required

Detecting and starting games

Installed games are read from Steam's own records on your disk. Play time, compatibility settings and launching do not use an API.

No key

Searching for a game to add

The Steam store search returns any game sold there without requiring a key.

Included

Importing a Steam library

This includes games you own but have not installed. A Steam key is included with the application, so the feature works immediately. The key is shared by all users, and Steam counts requests against it.

Key required

Artwork for non-Steam games

SteamGridDB provides cover images for games Steam does not sell, and several alternatives per game where Steam provides one. No key for this service is included.

Obtaining a key

  1. 1.

    Sign in at steamgriddb.com

    Sign in with your Steam account. No registration form and no payment is required.

  2. 2.

    Open the API page in your profile

    Go to steamgriddb.com/profile/preferences/api, generate a key and copy it.

  3. 3.

    Enter the key in Settings

    Open Settings, then API, and paste the key. It is stored in your own configuration folder and is sent only to SteamGridDB when artwork is requested.

Using your own Steam key

This is optional and is worth doing if you import libraries frequently. The included key is a single quota shared by all users of Parallax. You can obtain your own at steamcommunity.com/dev/apikey and enter it in Settings → API. A key you enter is always used in preference to the included one.
