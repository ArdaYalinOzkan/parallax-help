Installing

You have the file. Here is the rest.

Installation steps for each package type. Open the section that matches the file you downloaded.

Windows Parallax-Launcher-Setup.exe
  1. 1

    Open the file

    It is in your Downloads folder, called something like Parallax-Launcher-Setup-3.6.0.exe. Double-click it.

  2. 2

    Let it run

    Windows used to stop this with a blue box and no longer does, so in all likelihood nothing happens here at all. If it does say something.

  3. 3

    Choose where it goes

    The installer asks, rather than deciding for you. It installs for your account only, so it needs no administrator password. When it finishes Parallax is in the Start menu.

Updates arrive inside the app after this — it checks on its own and offers them.

AppImage Any Linux — nothing to install

An AppImage is the whole program in one file. Nothing is installed and nothing is scattered around your system; you keep the file wherever you like and delete it when you are done.

  1. 1

    Put it somewhere it can stay

    Downloads is a folder people empty. ~/.local/bin or ~/Applications is a kinder home for something you intend to keep.

  2. 2

    Allow it to run

    Linux does not let a freshly downloaded file execute until you say so. In a file manager this is a checkbox in Properties; in a terminal it is one line:

    chmod +x Parallax-Launcher.AppImage
  3. 3

    Run it

    Double-click, or run it from the terminal. The first time it starts it adds itself to your application menu, so afterwards you can find it the way you find anything else.

Updates: Parallax replaces its own file in place. If it ever will not start after an update, this is covered here.

.deb Debian, Ubuntu, Mint, Pop!_OS

Two ways. Installing the file gives you the program; adding the repository gives you the program and every update after it, through the same system that updates everything else on your machine.

The file on its own

Double-click it, or:

sudo apt install ./parallax-launcher_3.6.0_amd64.deb

Installed this way, updates do not arrive on their own — the app will tell you when there is one, and you download the next file yourself.

The repository, so updates keep coming

Three lines, once. After this Parallax updates with everything else when you run your usual upgrade.

curl -fsSL https://apt.parallaxlauncher.com/key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/parallax.gpg
echo "deb [signed-by=/usr/share/keyrings/parallax.gpg] https://apt.parallaxlauncher.com stable main" | sudo tee /etc/apt/sources.list.d/parallax.list
sudo apt update && sudo apt install parallax-launcher

The key is what lets your system check that an update really came from this project. Without it apt refuses the repository, which is the correct thing for it to do.
