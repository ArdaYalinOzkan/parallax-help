Windows security warnings

This page explains why Windows used to block the installer, what to do if a warning still appears, and how to verify that the file you downloaded came from this project.

Why the warning no longer appears

Windows blocks programs it has not seen before through a feature called SmartScreen. As a file is downloaded and run by more people without incident, it is recorded as trusted. The Parallax installer has reached that point, so the warning is no longer shown.

This status applies to the installer file itself rather than to a certificate. A newly released version may therefore be treated as unknown again for a period, until it has been downloaded a sufficient number of times.

If a warning does appear

The warning is a blue window titled Windows protected your PC, with a single visible button labelled Don't run. The option to continue is behind the small link above it.

  1. 1.

    Select More info

    This is the underlined text above the button. Selecting it expands the window and displays the publisher line.

  2. 2.

    Select Run anyway

    A second button appears below. The installer then opens normally, and Windows does not ask about this file again.

Verifying the file

Every release is built publicly on GitHub's servers from the source code in the repository, and each file includes a signed statement identifying the commit it was built from. If you have the GitHub CLI installed:

Verify the origin of the file 
gh attestation verify "Parallax-Launcher-Setup-3.6.0.exe" --owner ArdaYalinOzkan

Alternatively, compare the checksum of the file with the one published by the build:

In PowerShell 
Get-FileHash .\Parallax-Launcher-Setup-3.6.0.exe -Algorithm SHA512

Compare the result with the sha512 value in latest.yml on the release page. That file is produced by the build, and the complete build log is public.
