Windows

It just installs.

The installer no longer triggers a Windows warning. This page explains why, what to do if one appears anyway, and how to verify the file yourself.

Why it changed

Windows keeps score. A program it has never seen gets stopped on sight; one that enough people have downloaded and run without anything going wrong stops being a stranger. Parallax has crossed that line, and the warning is gone.

That reputation is earned by the installer file itself, not by a certificate — so a brand-new release can be treated as a stranger again for a while, until it has been downloaded enough times. If that happens to you, the next section is all of it.

If Windows does say something

A blue box headed Windows protected your PC, with one visible button that says Don't run. The way forward is behind the small link, which is the whole reason it stops anybody:

  1. 1

    Click More info

    The small underlined text above the button. It expands the box and shows the publisher line.

  2. 2

    Click Run anyway

    A second button appears underneath. The installer then opens normally, and Windows will not ask again about this file.

Checking the file yourself

Reputation is Microsoft's opinion, not proof. If you want proof: every release is built in public, on GitHub's machines, from the source in the repository, and every file carries a signed statement naming the commit that produced it. With the GitHub CLI:

Verify where it came from 
gh attestation verify "Parallax-Launcher-Setup-3.6.0.exe" --owner ArdaYalinOzkan

Or compare the file's fingerprint against the one the build published:

In PowerShell 
Get-FileHash .\Parallax-Launcher-Setup-3.6.0.exe -Algorithm SHA512

Compare it with the sha512 line in latest.yml on the release page. That file is written by the build, whose whole log is public.
